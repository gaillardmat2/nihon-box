# Nihon Box 🇯🇵

Le Japon en poche : découverte (régions, cuisine, traditions, fêtes), langue (hiragana, katakana, phrases utiles avec audio), préparation de voyage (itinéraires, budget, convertisseur, liste de préparation) et quiz avec XP et badges.

Application statique (un seul `index.html`) servie par nginx dans un conteneur Docker, déployée sur Render.
